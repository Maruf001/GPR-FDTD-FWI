# Field Experiment 198: Controlled Archive Signature Preflight Integration Audit

Date: 2026-06-27

## Purpose

Check whether the DZT signature guard from runs `196` and `197` closes a real
gap in the controlled archive preflight path.

The older archive-shape preflight accepts any expected file that exists and is
nonempty. This run compares that shape-only decision against an integrated
shape-plus-signature decision on two candidate archives:

1. The current pending controlled archive.
2. The synthetic placeholder archive generated by the earlier preflight smoke.

This is a CPU-only integration audit. It does not create measured field
evidence, accept the archive, run DZT preprocessing, launch field FWI, use
GPU/HPC, run field 3D, or train neural networks.

## Interpretation

The old shape-only preflight is insufficient by itself. It marks the synthetic
placeholder archive as ready because all expected paths exist and are nonempty.
The integrated shape-plus-signature preflight rejects the same archive because
none of the nine expected DZT files pass the GSSI DZT signature guard.

This confirms that the signature guard should be part of controlled archive
preflight before checksum and intake acceptance.

## Decision

Use the integrated shape-plus-signature preflight before checksum/intake
acceptance. Keep controlled evidence, field FWI, GPU work, and field 3D/HPC
blocked until real controlled DZT files pass this guard and all downstream
gates.
