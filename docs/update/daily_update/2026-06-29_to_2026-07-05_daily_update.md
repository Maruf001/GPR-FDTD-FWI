# Daily Updates: 2026-06-29 to 2026-07-05

## Monday, June 29, 2026

Today I worked on establishing the 2D boundary element method (BEM) as a fast forward model for ground-penetrating radar (GPR) scattering. I started with a dielectric cylinder because this case has a known mathematical reference solution, which makes it a clean way to check whether the solver is producing the right scattered electric field before using it for rebar-like targets.

The error decreased steadily as the circular boundary was refined. With 8 panels the relative error was about 5.5%, with 16 panels it dropped to about 1.5%, and with 32 panels it dropped to about 0.4%. A panel is one short straight segment used to approximate the curved target boundary. This gave a useful first result: the 2D BEM calculation is converging in the expected direction, and the method is accurate enough to move from a textbook cylinder test toward a metal target in a ground-like setting.

Plan for Tuesday: compare the 2D BEM result with a finite-difference time-domain (FDTD) simulation for the same metal rebar-style target, using matched geometry, material contrast, source location, receiver positions, and electric-field component.

## Tuesday, June 30, 2026

Today I worked on the first matched 2D comparison between the boundary element method and the finite-difference time-domain method for a metal rebar-style target. The goal was to see whether the faster boundary-only calculation could reproduce the main scattered-field pattern from the grid-based wave simulation, while keeping the target, source, and receiver layout as consistent as possible.

The main scattered response was close enough to keep BEM as a serious fast-model candidate, but the remaining difference was not just a single scale factor. The mismatch changed with receiver position and frequency, which means the next source of error is likely tied to source shape, source height, receiver sampling, target-boundary resolution, and how the ground surface is represented. This was an important narrowing step: the comparison moved from asking whether BEM can work at all to identifying which modeling details must be controlled before it can be used as a reliable fast companion to FDTD.

Plan for Wednesday: separate the effects of target-boundary resolution, source placement, receiver placement, and amplitude scaling, then choose a BEM setting fast enough for repeated sweeps without losing the main scattering behavior.

## Wednesday, July 1, 2026

Today I worked on making the 2D BEM metal-target model efficient enough for repeated depth and material sweeps. A 16-panel target representation gave nearly the same scattered-field shape as the 32-panel reference while running about 3.3 times faster, so the 16-panel setting is now suitable for early screening and the 32-panel setting remains the higher-resolution check.

I then tested target depths from 0.25 m to 0.45 m and ground material contrasts in the same simplified air-over-ground setting. Peak signal strength changed very little: less than 0.02 decibel across the depth sweep and about 0.09 decibel across the tested material range. The waveform shape changed more than the peak amplitude, reaching about 4% across depth and about 6% across the full depth-and-material grid. This points to a practical interpretation rule: depth and material should not be inferred from peak amplitude alone; timing and waveform shape need to carry more weight.

Plan for Thursday: test how much transmitter-receiver spacing and antenna height affect the same response, because geometry errors may be larger than the depth and material effects measured so far.

## Thursday, July 2, 2026

Today I focused on source and receiver geometry, because the earlier depth and material sweeps showed that peak amplitude is a weak discriminator in the current 2D BEM setup. I varied transmitter-receiver spacing and antenna height around the same metal target and ground setting, then compared the resulting scattered responses against the baseline layout.

The geometry effect was much larger than the depth and material effects. Changing transmitter-receiver spacing over the tested range produced about a 2.62 decibel peak-amplitude span and about a 71% waveform-shape difference, while antenna height produced a smaller but still important waveform change of about 42%. A finer 5 mm spacing test still produced about a 0.64 decibel peak-amplitude span and about a 17% waveform-shape difference. I then repeated the three baseline-height spacing cases with 32 panels instead of 16 panels, and the fine spacing signal was essentially unchanged. This means the result was not caused by using a coarse boundary; field measurements and matched FDTD comparison need explicit control of transmitter-receiver spacing, antenna standoff height, source and receiver coordinates, phase-center tracking, repeated scan geometry, and reference-scan geometry before depth or material differences can be interpreted with confidence.

Plan for Friday: start the matched finite-difference time-domain comparison around the locked source-receiver geometry, while keeping selected 32-panel BEM checks for final comparison points.
