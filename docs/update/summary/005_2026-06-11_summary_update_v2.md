Current Accumulated State of the project - June 11, 2026

  The project now has a mature synthetic GPR-FDTD-FWI pipeline for controlled rebar inversion. The strongest current branch is the 3-rebar variable-depth/variable-radius coordinate optimizer.

  The current synthetic truth used in the main branch is:

  target0: x=150 mm, z=80 mm,  radius=5 mm
  target1: x=250 mm, z=100 mm, radius=6 mm
  target2: x=350 mm, z=120 mm, radius=8 mm

  In these synthetic experiments, the “reference data” is generated by running FDTD on the known true scene. The
  optimizer then pretends it does not know the true x/z/r values. It tests candidate scenes, compares their
  simulated radar waveforms against the reference waveform, and picks the candidate with the lowest mismatch.

  So the goal is:

  FDTD(true scene) -> synthetic observed/reference waveform
  FDTD(candidate scene) -> candidate waveform
  objective/misfit = difference between them
  optimizer goal = minimize that difference

  Latest Validated Optimizer State

  This is important: the optimizer usually selects the correct geometry. The remaining issue is often not “wrong

  Intervention Evidence

  The latest report detected 117 multi-run experiment series:

  Source-density series: 62
  Tx/Rx-offset series:   33
  Ringdown series:       22

  Main conclusions:

  - Source-density changes often help, especially for target2, but more sources are not always better.
  - Tx/Rx-offset bracketing can rescue acquisition-sensitive cases, especially target0.
  - Ringdown tuning is useful but not a universal rescue.
  - Target1 has mixed behavior: some 9-source rescues work, but the latest 11-source escalation failed.

  Recent examples:

  1207-1209: target2 source-density rescue
  5 sources weak -> 7 sources near cutoff -> 9 sources accepted

  1211-1214: target0 Tx/Rx rescue
  60 mm weak -> 52.5 mm weak -> 50 mm accepted -> 45 mm accepted

  1216-1218: target1 source-density stop point
  5 sources weak -> 9 sources weak -> 11 sources worse

  Strongest Demonstrable Result

  The strongest result is now:

  A synthetic 3-rebar variable-depth/variable-radius FDTD/FWI workflow with noise/source mismatch, ringdown stress, bounded coordinate/radius search, exact geometry recovery across 425 evaluated runs, and explicit confidence reporting that avoids overstating weak radius separation.

  That is a mature synthetic inversion-and-reporting pipeline.

  It is not yet a mature field-data pipeline, and it is not yet a 3D pipeline.
