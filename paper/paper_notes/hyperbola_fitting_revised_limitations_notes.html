Bibliographic Details

Title: On the Limitations of Hyperbola Fitting for Estimating the Radius of Cylindrical Targets in Non-Destructive Testing and Utility Detection

Authors: Iraklis Giannakis, Feng Zhou, Craig Warren, Antonios Giannopoulos

Venue: IEEE Geoscience and Remote Sensing Letters

Main Claim

Conventional hyperbola fitting can estimate target depth and host-medium permittivity reasonably well, but it is not reliable for estimating cylindrical target radius when only first-arrival hyperbola shape is used.

The paper argues that practical GPR data always contain some combination of picking noise, time-zero error, antenna-positioning error, clutter, antenna noise, or medium heterogeneity. Under these normal conditions, many different radius/depth/permittivity combinations can generate almost indistinguishable hyperbolas.

This is a negative result for radius estimation, not a rejection of hyperbola fitting altogether. The method remains useful for fast location, cover depth, and bulk velocity/permittivity estimates.

Problem Setup

The paper considers ground-coupled GPR antennas moving along the x-axis, perpendicular to the long axis of a buried cylindrical target. The host medium is assumed to be a homogeneous non-magnetic half-space with relative permittivity epsilon_r.

Hyperbola fitting uses only first-arrival times. It is amplitude-agnostic, so it cannot infer target conductivity or target permittivity. It also does not use the waveform details that full waveform inversion uses.

Unknowns in the generalized hyperbola model:

  • x0: horizontal projection of the cylinder center.
  • d: cover depth.
  • R: cylinder radius.
  • epsilon_r: host-medium relative permittivity.

Forward Hyperbola Model

For a midpoint antenna coordinate x and half-offset w, the modeled two-way arrival time is: 

t = ((D_T + D_R) - 2R) * sqrt(epsilon_r) / c0

where:

D_T = sqrt((x + w - x0)^2 + (d + R)^2)
D_R = sqrt((x - w - x0)^2 + (d + R)^2)

Here c0 is the velocity of light in free space. The subtraction of 2R accounts for a finite-radius cylindrical target rather than a zero-radius point diffractor.

First-arrival picks are collected at positions: 

T in R^n at x = [x1, x2, ..., xn]

Optimization Formulation

The fitting problem is posed as least-squares arrival-time matching: 

argmin over x0, d, R, epsilon_r of (t - T) dot (t - T)^T

The paper uses a hybrid optimizer:

  1. Particle swarm optimization (PSO) as the global search stage.
  2. Simplex/local optimization using the PSO result as the starting point.

The authors state that PSO plus simplex is not essential; any global optimizer followed by any local optimizer could be used. The core issue is not optimizer quality. The core issue is non-uniqueness in the data-to-parameter mapping.

Figure 6: Time-Zero Error

Time-zero error is modeled as a constant shift in arrival times. The figure shows that time-zero mostly affects estimated depth and radius, while estimated permittivity is less affected. This is directly relevant to field GSSI data, where time-zero can be profile-dependent.

Figures 7 and 8: Numerical Utility Case

The gprMax numerical experiment contains three pipes with true radii [0.05, 0.10, 0.15] m at depths [0.65, 0.90, 0.90] m, embedded in a stochastic soil model with varying water fraction and host permittivity roughly 4-9.

Hyperbola fitting estimates permittivity and cover depth reasonably, but radius estimates are wrong: the reported fitted radii are [0, 0.32, 0] m, with about 140 percent average error.

Figures 9 and 10: Laboratory Concrete/Rebar Case

The laboratory experiment uses a mature concrete slab with six metallic rebars. The measurements are made perpendicular to the rebars using a commercial GSSI 2000 MHz palm antenna. This figure is especially relevant to our field-data work because it is a real GSSI rebar B-scan.

The authors constrain radius to four candidate values, R = [0, 0.015, 0.030, 0.045] m. For all candidate radii, the optimizer can find corresponding depth/permittivity values that fit the measured hyperbolas. This demonstrates that measured rebar hyperbolas do not uniquely determine radius.

Main Conclusions

  • Hyperbola fitting is useful for fast target localization, cover depth, and approximate medium permittivity.
  • Radius estimation from first-arrival hyperbola shape alone is non-unique.
  • Even less than 2 percent arrival-time noise can produce up to 500 percent radius error.
  • Time-zero errors mainly affect depth and radius.
  • Realistic medium heterogeneity makes the fitted hyperbola asymmetric or misshaped, worsening the radius ambiguity.
  • The only reliable ways around the radius ambiguity are near-noiseless data, independent constraints on depth/permittivity, or methods that use more information than first-arrival shape.

Relevance to Our GSSI 51600S Field Data

This paper should be treated as a fast baseline and identifiability warning, not as a final radius-estimation method.

Directly useful pieces for our data:

  • Use hyperbola fitting to estimate approximate rebar lateral position.
  • Use hyperbola fitting to estimate cover depth and effective concrete permittivity.
  • Run radius sweeps to show whether the field B-scans actually constrain radius.
  • Use the spread of acceptable radii as an uncertainty diagnostic.
  • Use time-zero sensitivity tests because time-zero shifts can strongly bias depth/radius.

What it cannot do alone:

  • It cannot reliably estimate rebar radius from the B-scan arrival curve alone.
  • It cannot estimate rebar material properties because amplitudes and waveforms are not used.
  • It cannot replace Jazayeri-style SBD plus FWI if diameter is the target quantity.

How To Test This Paper Separately On Our Field Data

  1. Select one clear GSSI B-scan profile from data/2026-06-09_GSSI_model_51600S.
  2. Apply only the preprocessing needed for arrival picking: time-zero correction, dewow/background removal, bandpass if needed, and gain normalization for display.
  3. Pick first-arrival points along each visible hyperbola.
  4. Fit {x0, d, R, epsilon_r} using the paper's PSO plus local optimization formulation.
  5. Repeat with multiple noise realizations or bootstrap pick perturbations.
  6. Repeat with constrained radius values to test whether many radii fit equally well.
  7. Report parameter ranges, not just one best-fit value.
  8. Use the result as an initial model or uncertainty bound for a separate FWI method.

The output should include hyperbola overlays for several acceptable radii. If the overlays are visually indistinguishable, that is evidence that the field data do not constrain radius by hyperbola shape alone.

Implementation Notes

Minimal code components needed:

  • First-arrival pick loader or picker.
  • Forward hyperbola function using non-zero transmitter-receiver offset.
  • PSO global search over bounded x0, d, R, epsilon_r.
  • Local optimizer refinement, such as Nelder-Mead or least-squares.
  • Bootstrap/noise perturbation of arrival picks.
  • Radius-constrained fitting mode.
  • Overlay plot of measured picks and fitted hyperbolas.
  • Summary table of accepted parameter ranges.

Bounds should be physically constrained for our concrete data. For example, epsilon_r should be in a plausible concrete range, and radius should span expected rebar sizes rather than unbounded utility-scale pipes.

Risks and Caveats

  • If arrival picking uses the wrong phase lobe, all fitted parameters can shift.
  • If the profile is not perpendicular to the rebar, the 2-D hyperbola model is biased.
  • If the concrete is layered or heterogeneous, the homogeneous half-space assumption is violated.
  • If antenna offset or time-zero is unknown, depth and radius become even less reliable.
  • If multiple rebars overlap, first-arrival picks may mix events from different bars.

One-Sentence Takeaway

Hyperbola fitting is valuable for quick rebar position, cover depth, and concrete permittivity estimates, but this paper shows it should not be trusted as a standalone method for rebar radius estimation from our field B-scans.
